Ejercicio 2

Usa las herramientas de desarrollador para poner breakpoints en aboutme.js y en console.log("Ej 1") de index.js. ¿Qué se ejecuta antes y por qué?

Solución:

El contenido del fichero aboutme.js se ejecuta antes que la llamada a console.log("Ej 1") en index.js. Esto se debe a la forma en que funcionan los módulos de JavaScript (import). Cuando se importa un módulo, su código se evalúa (ejecuta) en el momento de la importación. Dado que la línea import "./aboutme.js"; aparece antes de console.log("Ej 1");, el script aboutme.js se procesará primero.

Ejercicio 4

Dado el bucle for(var i = 0; i < 101; i++) { /* ... */ } console.log(i);, ¿qué valor tendrá i al finalizar y por qué? ¿Cómo evitar que i sea global?

Solución:

  • Valor de i: La variable i tendrá el valor 101 al finalizar el bucle.
  • Por qué: El bucle for se ejecuta mientras la condición i < 101 sea verdadera. Cuando i alcanza el valor 100, la condición 100 < 101 es verdadera, el bloque del bucle se ejecuta, y luego i se incrementa a 101. En la siguiente iteración, la condición 101 < 101 es falsa, y el bucle termina. Como i fue declarada con var, su alcance es la función contenedora (o global si no está dentro de una función), por lo que console.log(i) fuera del bucle puede acceder a su último valor.
  • Evitar declaración global: Sí, usando let en lugar de var para declarar la variable i. let tiene un alcance de bloque ({}), lo que significa que i solo existiría dentro del bucle for.

for(let i = 0; i < 101; i++) {
    // Solución
}
// console.log(i); // Esto daría un error: "i is not defined"

Ejercicio 5

¿Cuáles son las diferencias entre ejecutar un fichero JavaScript en formato <script> y <script type="module">?

Solución:

Característica <script> (Clásico) <script type="module">
Modo Estricto No está en modo estricto por defecto. Siempre está en modo estricto ('use strict';) por defecto.
Alcance (Scope) Las variables de nivel superior son globales (window). Las variables de nivel superior tienen alcance de módulo (local al módulo).
import/export No se pueden usar. Se pueden usar para modularizar el código.
Carga Síncrona por defecto. Se puede usar async o defer. Diferida (defer) por defecto.
CORS No requiere CORS para scripts del mismo origen. Requiere CORS para scripts de diferente origen.
Comportamiento this this en el nivel superior es window. this en el nivel superior es undefined.
Duplicados Se ejecuta varias veces si se incluye varias veces. Un módulo solo se ejecuta una vez.

Ejercicio 6

Crea un objeto formatter con un atributo prefix y un método append. Luego, añade un método toLowerString al objeto.

Solución:


console.log("Ejercicio 6");

const formatter = {
  prefix: "Hello ",
  append: function(cadena) {
    console.log(this.prefix + cadena);
  }
};
formatter.append("World"); // Result: Hello World

formatter.toLowerString = function(cadena) {
  console.log(cadena.toLowerCase());
};
formatter.toLowerString("I’m Lucas"); // Result: i’m lucas

// Solución alternativa usando prototipo de constructor:
function FormatterConstructor(prefix) {
  this.prefix = prefix;
}
FormatterConstructor.prototype.append = function(cadena) {
  console.log(this.prefix + cadena);
};
FormatterConstructor.prototype.toLowerString = function(cadena) {
  console.log(cadena.toLowerCase());
};
const myFormatter = new FormatterConstructor("Hi ");
myFormatter.append("There");
myFormatter.toLowerString("THIS IS LOUD");

Ejercicio 2

Enumera los distintos valores de "this" y las diferencias entre arrow functions y function expressions.

Solución:

Valores de this:

  1. Contexto Global (navegador): window.
  2. Contexto Global (Node.js): {} o module.exports.
  3. Método de un Objeto: El objeto que llama al método.
  4. Función Simple (No estricto): window.
  5. Función Simple (Estricto): undefined.
  6. Constructor (new): La nueva instancia creada.
  7. Arrow Functions: El this del contexto léxico que las rodea.
  8. Event Handlers DOM: El elemento DOM que disparó el evento.
  9. call(), apply(), bind(): El valor de this explícitamente establecido.

Diferencias Arrow Functions vs Function Expressions:

Característica Arrow Function (=>) Function Expression (function() {})
this binding Hereda this del scope padre. Tiene su propio this.
arguments object No tiene. Usar rest parameters. Tiene su propio objeto arguments.
Uso como constructor No (lanza TypeError). Sí.
prototype property No. Sí.
yield keyword No. Sí (para generadores).

Ejercicio 2

Función sumOrConcatenate(a: number | string, b: number | string) que sume si ambos son números, concatene con "-" si son strings, o con "+" si son mixtos.

Solución:


console.log("\\nEjercicio 2 - TypeScript");

function sumOrConcatenate(a: number | string, b: number | string): number | string {
  if (typeof a === 'number' && typeof b === 'number') {
    return a + b;
  } else if (typeof a === 'string' && typeof b === 'string') {
    return `${a}-${b}`;
  } else {
    return `${a}+${b}`;
  }
}

console.log(sumOrConcatenate(4, 3)); // 7
console.log(sumOrConcatenate(4, "hello")); // "4+hello"
console.log(sumOrConcatenate("4", 3)); // "4+3"
console.log(sumOrConcatenate("hello", "world")); // "hello-world"

Ejercicio 3

Interfaces Car y Motorcycle con propiedades específicas. Función que acepte Car | Motorcycle, llame a turnOnEngine() y luego al método específico (pressPedal o openThrottle) usando type predicates.

Solución:


console.log("\\nEjercicio 3 - TypeScript");

interface Car {
  tires: number;
  turnOnEngine: () => void;
  pressPedal: () => void;
}

interface Motorcycle {
  tires: number;
  turnOnEngine: () => void;
  openThrottle: () => void;
}

function isCar(vehicle: Car | Motorcycle): vehicle is Car {
  return (vehicle as Car).pressPedal !== undefined;
}

function operateVehicle(vehicle: Car | Motorcycle): void {
  vehicle.turnOnEngine();
  if (isCar(vehicle)) {
    vehicle.pressPedal();
  } else {
    (vehicle as Motorcycle).openThrottle(); // Type assertion si es necesario
  }
}

const myCar: Car = {
  tires: 4,
  turnOnEngine: () => console.log("Car engine ON"),
  pressPedal: () => console.log("Car pedal pressed")
};
const myMotorcycle: Motorcycle = {
  tires: 2,
  turnOnEngine: () => console.log("Motorcycle engine ON"),
  openThrottle: () => console.log("Motorcycle throttle opened")
};

operateVehicle(myCar);
operateVehicle(myMotorcycle);

Ejercicio 4

Función genérica que acepte un array (string[] | number[] | (string|number)[]) y devuelva el mismo array sin el primer elemento, sin usar any.

Solución:


console.log("\\nEjercicio 4 - TypeScript");

function removeFirstEntry<T extends (string | number)>(arr: T[]): T[] {
  if (arr.length === 0) {
    return [];
  }
  return arr.slice(1);
  // Alternativa: const [, ...rest] = arr; return rest;
}

const strArray: string[] = ['Hello', 'World', 'Im', 'a', 'Full', 'Stack', 'Developer'];
const numArray: number[] = [1, 2, 3, 4, 5, 6, 7];
const mixedArray: Array<number | string> = ['Hello', 'I', 'have', 3, 'tasks'];

console.log(removeFirstEntry(strArray));
console.log(removeFirstEntry(numArray));
console.log(removeFirstEntry(mixedArray));
console.log(removeFirstEntry([])); // []
